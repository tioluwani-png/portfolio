2026 · Founder · Current stop

FLOIN

Bookkeeping for Nigerian traders, inside the app they already use all day. A trader types a sale, an expense or a debt in plain words and FLOIN keeps the books.

  • Started as a web dashboard. I moved it to WhatsApp because that is where traders already are.
  • The AI only reads the message. SQL does every calculation, so the totals are never guessed.
  • The parser handles Pidgin and broken English, tested on live chats.
Working product
